# Northvolt

> Northvolt AB was a Swedish lithium-ion battery developer and manufacturer, founded in
> Stockholm in 2016. It built and operated the Northvolt Ett gigafactory in Skelleftea and
> the Northvolt Labs R&D and qualification campus in Vasteras, with further sites in Heide
> (Germany), Gdansk (Poland) and Montreal (Canada). Northvolt AB filed for bankruptcy on
> 12 March 2025; its remaining assets were acquired by Lyten during 2025.

## Status of this profile

This file was GENERATED by API Evangelist from the company's public website on 2026-08-26.
Northvolt did not publish an llms.txt of its own -- https://northvolt.com/llms.txt returns
HTTP 200 with the site's soft-404 HTML shell, not a document.

**Northvolt publishes no API.** There is no developer portal, no API reference, no OpenAPI,
AsyncAPI, GraphQL SDL, Protobuf or WSDL contract, no SDK, no CLI, no MCP server and no A2A
agent card. Every discovery path in the API Evangelist enrichment pipeline was probed and
missed. The one host that ever looked like an API host, https://api.northvolt.com, resolves
to a CloudFront distribution whose origin is gone -- every path returns HTTP 502.

## Products (marketing pages, no machine-readable interface)

- [Battery cells](https://northvolt.com/products/cells/): lithium-ion, sodium-ion and lithium-metal cells
- [Battery systems](https://northvolt.com/products/systems/): Voltpack Core, Voltpack Mobile System
- [Connected Battery](https://northvolt.com/products/systems/connected-battery/): battery fleet management, remote diagnostics and over-the-air updates. Customer-only; the sign-in is at https://cloud.northvolt.com/ which redirects to https://login.northvolt.com/. No public API is documented for it.
- [Revolt recycling](https://northvolt.com/recycling/): battery recycling into raw materials
- [Manufacturing](https://northvolt.com/manufacturing/): Northvolt Ett, Northvolt Labs, Northvolt Six

## Open source

The [github.com/northvolt](https://github.com/northvolt) organization publishes first-party
Go modules for factory-floor hardware -- go-multicam (Euresys frame grabbers), go-sapera
(Teledyne SaperaLT), go-kd6rmx (Mitsubishi contact image sensors), go-atecc-old (Microchip
ATECC608). These are hardware drivers, not API client libraries. The rest of the
organization is forks of third-party open source. Latest first-party release: v0.1.0 of
go-atecc-old, 2025-03-06.
